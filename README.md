# 贪吃蛇游戏

这是一个使用C/C++开发的经典贪吃蛇游戏，基于EasyX图形库实现可视化界面。

## 项目介绍

本项目实现了一个经典的贪吃蛇游戏，使用链表数据结构来管理蛇身，通过EasyX图形库在Windows平台上绘制游戏界面。

### 主要特性

- 🎮 经典贪吃蛇游戏玩法
- 🐍 使用链表数据结构管理蛇身
- 🎨 基于EasyX图形库的可视化界面
- 🍎 随机生成食物
- 🏆 碰撞检测（墙壁和蛇身）
- ⌨️ 方向键控制

## 技术栈

- **语言**: C/C++
- **图形库**: EasyX
- **数据结构**: 链表
- **平台**: Windows

## 项目结构

```
贪吃蛇/
├── 贪吃蛇/
│   ├── 贪吃蛇.cpp      # 主程序文件
│   ├── LinkList.c       # 链表实现
│   ├── LinkList.h       # 链表头文件
│   ├── resource.h       # 资源定义
│   └── 贪吃蛇.rc        # 资源文件

```

## 编译与运行

### 环境要求

- Visual Studio 2019 或更高版本
- EasyX 图形库

### 编译步骤

1. 使用 Visual Studio 打开 `贪吃蛇.sln` 解决方案文件
2. 确保已安装 EasyX 图形库
3. 编译项目（Ctrl+Shift+B）
4. 运行程序（Ctrl+F5）

### 游戏操作

- **↑↓←→** 方向键控制蛇的移动方向
- 吃到食物蛇身变长
- 撞到墙壁或蛇身游戏结束
